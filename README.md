# FIL-IO-AI notebooks

Starter notebooks for the Polish AI Olympiad (OAI) preparation class.

| Notebook | Open |
|---|---|
| Pandas intro — the most useful functions, step by step | [Open in Colab](https://colab.research.google.com/github/spassistai/FIL-IO-AI-notebooks/blob/main/pandas/intro.ipynb) |
| Pandas — 30 short exercises | [Open in Colab](https://colab.research.google.com/github/spassistai/FIL-IO-AI-notebooks/blob/main/pandas/exercises.ipynb) |
| Logistic regression — binary (sigmoid) and multiclass (softmax) on MNIST | [Open in Colab](https://colab.research.google.com/github/spassistai/FIL-IO-AI-notebooks/blob/main/classifiers/logistic-regression.ipynb) |
| PyTorch classifier — logistic regression vs a small neural network on MNIST | [Open in Colab](https://colab.research.google.com/github/spassistai/FIL-IO-AI-notebooks/blob/main/classifiers/pytorch-classifier.ipynb) |
| Digit Recognizer — load data, nearest-centroid baseline, evaluation, mistakes | [Open in Colab](https://colab.research.google.com/github/spassistai/FIL-IO-AI-notebooks/blob/main/digit-recognizer/starter.ipynb) |

The notebook runs anywhere: on Kaggle it uses the competition files, elsewhere (e.g. Colab) it downloads
the same MNIST digits from OpenML. To submit to [Kaggle Digit Recognizer](https://www.kaggle.com/competitions/digit-recognizer),
follow the optional Kaggle API cell in section 1.
